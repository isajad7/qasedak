# مستندات پروژه قاصدک برای اکوسیستم آزادنت

آخرین بررسی: 2026-08-04

این پوشه یک لایه مستندات محصولی و معماری برای پروژه فعلی می‌سازد. سندهای موجود پروژه بیشتر نصب، عملیات و troubleshooting را پوشش می‌دهند؛ این مجموعه برای پلنینگ، انتقال دانش، تصمیم‌گیری محصولی و جای دادن قاصدک در اکوسیستم آزادنت نوشته شده است.

## نقشه سندها

| سند | کاربرد |
| --- | --- |
| `01-product-overview-fa.md` | ایده محصول، جایگاه در آزادنت، بازیگران، ارزش‌ها و دامنه‌های اصلی |
| `02-architecture-fa.md` | معماری فنی، ماژول‌ها، مدل داده، یکپارچه‌سازی‌ها و تصمیم‌های مهم پیاده‌سازی |
| `03-workflows-fa.md` | روندهای کاری کاربر، ربات، ادمین، پرداخت، provisioning، پشتیبانی، کمپین و عملیات |
| `04-features-and-planning-fa.md` | موجودی فیچرها، وضعیت پیاده‌سازی، محدودیت‌ها، ریسک‌ها و پیشنهاد پلنینگ آینده |

## خلاصه خیلی کوتاه

قاصدک یک سیستم مستقل فروش و مدیریت کانفیگ VPN با Django است که هم وب‌اپ فروش دارد و هم بازوی اصلی فروش تلگرامی را مدیریت می‌کند. پروژه روی فروش کانفیگ، پرداخت کارت‌به‌کارت، بررسی رسید، اتصال به X-UI/Sanaei، تحویل کانفیگ، داشبورد ادمین، مدیریت سرویس‌ها، پشتیبانی، کمپین، Revenue Engine، بکاپ/ریستور و مسیر محصول‌سازی چندمستاجری تمرکز دارد.

## دامنه بررسی

این مستندات بر اساس کد و فایل‌های محلی همین workspace تهیه شده‌اند. در زمان بررسی، worktree تغییرات ثبت‌نشده در چند فایل کد داشت؛ این سندها آن تغییرات را بازنویسی نکرده‌اند و فقط فایل‌های جدید داخل `docs/azadnet/` اضافه شده‌اند.
